# Eli Allen: Profile

Source HTML for Eli Allen's personal profile page.

**Live site:** https://eli.availabooks.com
Hosted on Cloudflare Pages (project: eli-allen-profile). Backup address: https://eli-allen-profile.pages.dev/

## Editing

`index.html` is the whole page: one self-contained file with all styles and images inlined. Edit it on any platform, commit, and the file here is the source of truth for the next redeploy to Cloudflare Pages.

Note: this repo holds the published HTML export. The interactive original lives in Muse as the eli-allen-profile artifact; bigger redesigns are easier there, then re-exported to this file.
